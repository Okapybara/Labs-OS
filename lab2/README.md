#### Лабораторная работа №2

---

Вариант 13.

Реализовать параллельную версию алгоритма свертки квадратной матрицы вещественных чисел с использованием POSIX Threads. Исходная матрица и фильтр генерируются программно. Параллельная версия распределяет строки матрицы между рабочими потоками, синхронизация между итерациями обеспечивается барьером. Дополнительно реализована последовательная версия для сравнения производительности.

Компиляция: ```gcc -pthread main.c -o lab2```

Запуск: ```./lab2 --size <N> --window <W> --iterations <I> --threads <T>```
--size — размер матрицы (1–10000)
--window — размер фильтра, нечётный (1–11)
--iterations — число итераций свёртки (1–10000)
--threads — число рабочих потоков (1–10000)

Запуск с просмотром количества потоков:
```strace -f -e trace=clone3 ./lab2 --size <N> --window <W> --iterations <I> --threads <T>```
