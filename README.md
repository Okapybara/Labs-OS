### Лабораторная работа №1. Крайнова Ольга. М8О-213БВ-25

---

Вариант 13.

Условие варианта:
Родительский процесс принимает от пользователя строки произвольной длины и передает их через цепочку дочерних процессов для обработки:
- child1 — переводит все символы строки в нижний регистр;
- child2 — заменяет все пробельные символы (пробел, табуляция, перевод строки и т.д.) на символ подчеркивания '_';
- Родитель — выводит итоговый результат на стандартный вывод (терминал).

Компиляция:
gcc child1.c -o child1
gcc child2.c -o child2
gcc parent.c  -o parent

Запуск: ./parent
